### Missing Persons Identification & Tracking System

An AI-assisted decision-support platform for comparing new sightings against open missing-person cases. It supports human reviewers; it does not make identifications on its own.

| | |
|---|---|
| **Problem** | Reviewers must manually compare new sightings with many open cases. The system surfaces possible matches to prioritise human review. |
| **Stack** | `Python` `MediaPipe Face Landmarker` `K-Nearest Neighbours` `SQLite` (verify against the repository) |
| **Responsible design** | Human review of every match, privacy protection for sensitive data, audit logging, and clear communication that automated facial comparison is error-prone. |
